# Expense Tracker - Трекер расходов

Приложение для учета личных расходов с поддержкой множества валют, категорий, графиков и уведомлений о превышении лимитов.

## 📋 Функциональные требования

### Основные функции
- ✅ **Добавление расходов** - быстрое добавление новых трат с указанием суммы, категории и описания
- ✅ **Редактирование и удаление расходов** - изменение или удаление существующих записей с подтверждением
- ✅ **Отображение расходов по категориям** - визуальное представление категорий с иконками и цветами
- ✅ **Подтверждение действий через диалоговое окно** - защита от случайных удалений
- ✅ **Хранение данных в локальной базе** - использование Room для офлайн-хранения
- ✅ **Уведомление при превышении установленного лимита** - push-уведомления при превышении месячного бюджета

### Дополнительные возможности
- ✅ **Дневная и месячная статистика** - отслеживание расходов за день и месяц с прогресс-барами
- ✅ **Поиск и фильтрация расходов** - поиск по описанию и фильтрация по категориям
- ✅ **Графики расходов** - круговая диаграмма по категориям и столбчатая диаграмма по дням
- ✅ **Настройки валюты** - поддержка 8 валют (UZS по умолчанию, RUB, USD, EUR и др.)
- ✅ **Настройка лимитов** - индивидуальные дневные и месячные лимиты
- ✅ **Профиль приложения** - информация о версии, лицензиях и возможностях

## 🏗 Архитектура приложения

### MVVM (Model-View-ViewModel)

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   UI Layer      │────▶│  ViewModel      │────▶│  Repository     │
│   (Compose)     │◀────│  (StateFlow)    │◀────│  (Flow)         │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                        │
                                                        ▼
                                               ┌─────────────────┐
                                               │  Data Sources   │
                                               │  (Room/         │
                                               │   DataStore)    │
                                               └─────────────────┘
```

### Data Layer

#### Entity (Сущность)
**Expense** - основная сущность расхода:
```kotlin
@Entity(tableName = "expenses")
data class Expense(
    @PrimaryKey(autoGenerate = true) val id: Int = 0,
    val amount: Double,
    val category: String,
    val description: String,
    val date: Date
)
```

#### DAO (Data Access Object)
**ExpenseDao** - интерфейс доступа к данным:
- `insert(expense: Expense)` - добавление расхода
- `update(expense: Expense)` - обновление расхода
- `delete(expense: Expense)` - удаление расхода
- `getAll(): Flow<List<Expense>>` - получение всех расходов
- `getByCategory(category: String)` - фильтрация по категории
- `search(query: String)` - поиск по описанию
- `getSum(start: Long, end: Long)` - сумма за период

#### Repository
**ExpenseRepository** - абстракция над источником данных:
- Обеспечивает единый интерфейс для работы с данными
- Использует Flow для реактивных обновлений
- Выполняет операции в фоновом потоке

**SettingsRepository** - управление настройками:
- Хранит валюту, лимиты в DataStore
- Предоставляет Flow для наблюдения за изменениями

### UI Layer

#### Screens (Экраны)

**HomeScreen** - главный экран:
- Статистика за день и месяц
- Список расходов с поиском
- Фильтрация по категориям
- Нижняя навигация

**AddExpenseScreen** - добавление расхода:
- Поля для суммы и описания
- Выпадающий список категорий
- Диалог подтверждения

**SettingsScreen** - настройки:
- Выбор валюты из 8 вариантов
- Настройка дневного и месячного лимитов

**StatisticsScreen** - статистика:
- Круговая диаграмма по категориям
- Столбчатая диаграмма по дням
- Детализация по категориям

**ProfileScreen** - профиль:
- Информация о приложении
- Список лицензий
- Версия приложения

#### ViewModel

**ExpenseViewModel** - управление состоянием:
- Хранит StateFlow для всех UI-состояний
- Обрабатывает пользовательские действия
- Взаимодействует с репозиториями
- Проверяет лимиты и отправляет уведомления

### Navigation

Используется Navigation Compose с графом:
- `home` - главный экран
- `add_expense` - добавление расхода
- `settings` - настройки
- `profile` - профиль
- `statistics` - статистика

## 📱 Руководство пользователя

### Добавление расхода
1. Нажмите кнопку **+** на главном экране
2. Введите сумму расхода
3. Выберите категорию из выпадающего списка
4. Добавьте описание (опционально)
5. Нажмите "Добавить расход"
6. Подтвердите действие в диалоге

### Изменение валюты
1. Откройте экран **Настройки** (иконка шестеренки)
2. Нажмите на поле "Текущая валюта"
3. Выберите нужную валюту из списка
4. Изменения применятся автоматически

### Установка лимитов
1. Перейдите в **Настройки**
2. Введите желаемый месячный лимит
3. Введите желаемый дневной лимит
4. Нажмите Enter для сохранения

### Просмотр статистики
1. Нажмите **Статистика** в нижней навигации
2. Просмотрите круговую диаграмму по категориям
3. Изучите столбчатую диаграмму по дням
4. Проанализируйте детализацию по категориям

### Поиск и фильтрация
- Используйте поле поиска на главном экране для поиска по описанию
- Нажмите на чип категории для фильтрации
- Нажмите "Все" для сброса фильтра

## 🗄 Схема базы данных

### Таблица `expenses`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ, автоинкремент |
| amount | REAL | Сумма расхода |
| category | TEXT | Название категории |
| description | TEXT | Описание расхода |
| date | INTEGER | Timestamp в миллисекундах |

### Индексы
- Первичный ключ: `id`
- Индекс по дате: `date DESC` (для сортировки)
